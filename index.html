展开：完整方法与复现范围 展开
算法与损失
dr_grpo：组内减均值，不除以组标准差，不做 batch whitening。PPO tokenwise clipped surrogate；按全局 action token 数求平均，ratio clip = [0.8, 1.2]。
奖励与正则
数学正确性 0/1；KL、熵与辅助损失系数均为 0，importance-sampling correction 关闭。
量化频率
每次 optimizer step 后物化 q；每次非最终评估后，SR 额外重新抽样并同步给 rollout。Chunk 末尾待执行的 refresh 在恢复后执行一次；RNE refresh 是确定性的。
对照实现
两臂均使用显式 q 物化，RNE 不是未经修改的 vanilla MoLT。FP32 master 恢复 → 原生 AdamW 更新 → 保存 master → RNE / SR 量化为 q。
精度与运行
29 个 FSDP2 模块 / 2 ranks；FP32 DTensor 存储 BF16 网格 q。HF BF16 autocast 并非所有算子都用 BF16。原生 eager AdamW，foreach=false，fused=false；无 TE。
优化器参数
β=(0.9, 0.999)，ε=1e−8，weight decay=0.01；梯度裁剪 norm=1；恒定 LR=1e−6，无 warmup，完整 gradient checkpointing。
训练采样
24 题 × 8 次 = 192 响应 / 步；每 rank micro batch=2。temperature=1，top_p=1，context=4,096，输出上限=2,048。paired_v1 对齐逻辑请求 seed，不保证生成逐位相同。
评分器修正
仅从 response 提取答案并评分，移除了从 prompt+response 回退提取的路径，避免题目内容泄漏到答案。解析失败记 0；不声称与原 RFZ / MoLT 评分器逐位一致。
数据与模型版本
复现边界
使用 RFZ 命名的训练数据与固定公开评测文件；未获得其全部评测文件与模板的逐字节基准。OlympiadBench 保留公开版本全部 675 题（论文为 674），未为匹配数量删题。
